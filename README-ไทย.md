# Badminton Live (แอป Android)

แอปไลฟ์แบดมินตันขึ้นเพจ Facebook พร้อมโอเวอร์เลย์สกอร์

## สร้างไฟล์ติดตั้ง (APK) ด้วย GitHub
1. สมัคร/ล็อกอิน github.com แล้วกด + > New repository ตั้งชื่อ `badminton-live` กด Create repository
2. กด "uploading an existing file" แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ไปวาง กด Commit changes
3. ถ้าโฟลเดอร์ `.github` ไม่ถูกอัปโหลด (บน Mac โฟลเดอร์ที่ขึ้นต้นด้วยจุดจะถูกซ่อน):
   Add file > Create new file ตั้งชื่อ `.github/workflows/build-apk.yml` แล้ววางเนื้อหาจากไฟล์ในชุดนี้
4. เปิดแท็บ Actions รอให้ "Build APK" ขึ้นเครื่องหมายถูกสีเขียว (ครั้งแรก 5-15 นาที)
5. กดเข้ารอบที่สำเร็จ เลื่อนลงที่ Artifacts กด `badminton-live-apk` ดาวน์โหลด แตกไฟล์ จะได้ `app-debug.apk`
6. ส่งไฟล์เข้ามือถือ เปิดไฟล์ อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก ถ้ามีคำเตือนจาก Play Protect เลือกติดตั้งต่อ

## ใช้งาน
1. เปิดแอป อนุญาตกล้องและไมโครโฟน
2. ตั้งค่า > ไลฟ์ขึ้น Facebook: ใส่ Server URL และ Stream Key จาก Facebook เพจ > สร้างวิดีโอสด > ซอฟต์แวร์สตรีมมิ่ง
3. กด "● ไลฟ์" แล้วกลับไปกด "ไลฟ์" ใน Facebook เมื่อเห็นภาพตัวอย่าง

## ถ้า build ไม่ผ่าน
เปิดรอบที่ล้มเหลวในแท็บ Actions คัดลอกข้อความสีแดงส่งให้ Claude แก้
